# ToDo App

Simple Flutter to-do app: add, complete and delete tasks. A learning project.

## Features
- Add a task
- Mark a task as done
- Delete a task

## How to run
1. Install [Flutter](https://docs.flutter.dev/get-started/install)
2. Clone this repository:
   ```
   git clone https://github.com/gabrielncne/todo_app.git
   cd todo_app
   ```
3. Get the dependencies and run:
   ```
   flutter pub get
   flutter run
   ```
